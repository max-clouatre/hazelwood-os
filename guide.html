Play Pad: getting it onto the tablet

How this works

Play Pad is a PWA (progressive web app): a normal web page plus two small files that let Chrome treat it like an installed app.

  • docs/manifest.webmanifest tells Android the app's name, icon, and that it should open fullscreen with no browser bars.
  • docs/sw.js is a service worker. On first visit it copies the app's files into the tablet's storage, so afterwards it launches with no internet.

The only time the tablet needs a network is the first visit, to download the app from some web address. That's the "how do I get it onto the tablet" part. Everything after that is offline.

Important rule: Chrome only allows service workers (and real "Install app") on HTTPS pages or on localhost. A plain http://192.168.x.x address on your Wi-Fi does not qualify. That one fact drives the comparison below.

Option A: GitHub Pages (recommended)

  1. Merge the claude/greia-style-android-app-aoapd7 branch into main (or just publish from that branch while testing).
  2. On GitHub, open the repo → Settings → Pages.
  3. Under Build and deployment, set Source to Deploy from a branch. Choose branch main and folder /docs, then Save.
  4. Wait about a minute. The page will show your site address, which should look like https://<your-github-username>.github.io/obviously/.
  5. Open that address on your computer first. You should see a dark purple screen reading "Tap anywhere". If so, you're done with this step.

All paths in the app are relative, so it works fine under the /obviously/ sub-path.

Option B: Local server on your Wi-Fi (for quick testing)

  1. On your computer: 
    cd docs
python3 -m http.server 8000
    (or npx serve docs -l 8000)
  2. Find your computer's local IP: ipconfig getifaddr en0 (macOS), hostname -I (Linux), or ipconfig (Windows). It looks like 192.168.1.23.
  3. Put the tablet on the same Wi-Fi and open http://192.168.1.23:8000 in Chrome. The app will load and the touch interactions will work.
  4. To get true install + offline over plain http: on the tablet open chrome://flags, search "Insecure origins treated as secure", enable it, type http://192.168.1.23:8000 into the box, then tap Relaunch. Without this, "Add to Home screen" just creates a shortcut that needs the server running every time.
The IP can change when your router reassigns it. That's another reason to use GitHub Pages for the version the girls will actually use.

Option C: Netlify or Cloudflare Pages

Connect the repo, leave the build command empty, set the publish/output directory to docs. You'll get an HTTPS address. Good if you keep the repo private.

Step 2: Install on the tablet

Do this once, with the tablet connected to Wi-Fi.

With Chrome (recommended)

  1. Open Chrome and go to your app's address.
  2. Wait for the small pill in the top right to say "online · offline-ready ✓". That confirms the service worker has cached everything. If it says "not cached yet", wait a few seconds or reload once.
  3. Tap the ⋮ menu (top right) → Add to Home screen → Install (if you see both Install and Create shortcut, pick Install).
  4. Tap Install / Add to confirm. A rainbow-shapes icon named "Play Pad" appears on the home screen.

With Samsung Internet (works too)

  1. Open the address in Samsung Internet.
  2. Tap the ≡ menu (bottom right) → Add page to → Home screen → Add.
Chrome gives a cleaner fullscreen result. Use Chrome if you have a choice.

Step 4: Lock the tablet to the app

Pinning stops a 3-year-old from leaving the app. You have two options.

Option 1: Samsung screen pinning (works with any app)

  1. Turn it on once: Settings → search for "Pin windows" (usually under Biometrics and security → Other security settings). Switch it On.
  2. Also turn on "Ask for PIN before unpinning" so only you can exit. Set a PIN you'll remember.
  3. Pin the app: open Play Pad, then open Recents (the ▮▮▮ button, or swipe up and hold with gesture navigation). Tap the app icon at the top of Play Pad's card → Pin this app.
  4. Unpin: with button navigation, touch and hold Back + Recents together. With gesture navigation, swipe up with two fingers and hold. Enter your PIN.
Test the unpin gesture before handing the tablet over so you don't lock yourself out. The menu wording differs slightly between One UI versions; searching Settings for "pin" always finds it.

Option 2: Samsung Kids

If your tablet has the Samsung Kids mode (swipe down the quick panel → Kids), you can add Play Pad as an allowed app inside it and use its parental controls and timers. It's a good bridge until we build our own parent area.

Updating the app later

  1. Change files in docs/.
  2. Bump VERSION in docs/sw.js (e.g. playpad-v1 → playpad-v2). If you forget, tablets keep serving the old cached copy.
  3. Push to the branch GitHub Pages serves.
  4. On the tablet, open the app once while online, then close and reopen it. The new version takes over on the next launch. Pinned? Unpin first if you want to force a refresh.

Tip: if you add new files, add them to the ASSETS list in sw.js too, or they won't work offline.

Troubleshooting

SymptomLikely cause and fix
Pill says "not cached yet" foreverService worker didn't register. Check the address is https:// (or use the flag from Option B). Reload once. Make sure you're not in a private/incognito tab.
No "Install" option, only "Create shortcut"Same HTTPS problem, or you haven't loaded the page long enough. Wait for the offline-ready pill, then check the menu again.
GitHub Pages shows a 404It takes up to a few minutes after enabling. Confirm the source is main + /docs, and that the branch containing docs/ is merged. The URL is case-sensitive and ends with /obviously/.
Icon launches but a browser bar showsIt was added as a shortcut, not installed. Long-press the icon → remove, then redo Step 2 and choose Install. Or use Chrome instead of Samsung Internet.
No soundRaise media volume (not ringer). Make sure the tablet isn't on silent. Tap once first, since audio unlocks on a touch.
Fails when Airplane mode is onThe cache never filled. Go online, open the app, wait for "offline-ready ✓", and retest. Also try clearing Chrome's site data for the address and reloading.
Old version keeps showing after an updateYou didn't bump VERSION in sw.js, or the app hasn't been relaunched. Bump, push, open online, close fully, reopen. Last resort: Settings → Apps → Chrome → Storage → Manage storage, clear the site's data, then reinstall.
Page scrolls or zooms when kids touch itShouldn't happen. The app disables pinch-zoom and scroll. If it does, you probably have an old cached version. See the row above.
Can't get out of pinned modeHold Back + Recents (button nav) or two-finger swipe-up and hold (gesture nav), then enter your PIN. A reboot also clears pinning.
